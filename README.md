<h1>Quiz Platform with Certificate Generation</h1>
An interactive crypto quiz web application where users can test their knowledge and download a personalized PDF certificate upon completion. Built entirely with vanilla HTML, CSS, and JavaScript — no frameworks, no backend.

<h2>Features</h2>
<ul>
<li>User registration form (name + email)</li>
<li>Multi-question crypto quiz with instant feedback</li>
<li>Score calculation and results page</li>
<li>Downloadable PDF certificate generated in the browser</li>
<li>Certificate includes user's name, email, score, and date</li>
<li>Fully client-side — zero server required</li>
</ul>

**Tech Stack**<br/>
HTML5: Structure and form handling<br/>
CSS3: Styling and responsive layout<br/>
JavaScript (ES6+): Quiz logic and state management<br/>
pdf-lib: Client-side PDF generation<br/>
